# Synthetic-Microbiome-Reproduction
# 🌱 拟南芥根系合成菌群(SynCom)对磷胁迫响应的重现分析

本项目为华中农业大学资源与环境学院的复现作业。核心旨在基于高通量测序数据，重现 Castrillo 等人 (2017) 发表在 *Nature* 上的经典植物微生态研究结果。

## 📊 项目概览

植物在面临营养元素缺乏（如低磷胁迫）时，会主动调节其根系微生物组的装配。本项目通过自动化 Python 脚本，提取并清洗了原文献的 Supplementary Dataset 2 (OTU 丰度表与样本 Metadata)，完成了以下核心生信分析：

1. **群落组成分析**：计算并可视化了 96 个样本中 Top 10 核心优势菌株的相对丰度堆叠图。
2. **核心样本 PCoA 降维聚类**：采用 Scikit-learn 对“正常磷 (+P)”与“低磷 (-P)”条件下的野生型接种样本进行亚组隔离分析。PC1 轴解释了超过 30% 的群落结构变异，完美重现了**磷浓度变化重塑根系微生物组结构**的核心结论。

## 📂 仓库结构

* `data/`: 存放原文献核心数据的 Excel 文件。
* `reproduction_report.qmd`: 包含完整数据抓取、清洗、降维算法及可视化的 Quarto 源代码文件。
* `reproduction_report.html`: 最终一键渲染生成的**精美图文交互式网页报告**（强烈建议下载后用浏览器打开预览）。

## 🛠️ 技术栈

* **核心语言**: Python 3
* **数据处理与降维**: `pandas`, `scikit-learn`
* **学术可视化**: `matplotlib`, `seaborn`
* **报告渲染引擎**: Quarto
